# This folder must be populated by you
1. We do not add DBC due to Blizzard Entertainment copyrighted material
2. mysql/init/*.sh will be ran inside of docker containers to initialize the db. Mangosd will fill most of it.
3. ./maps/ ./mmaps ./vmaps/ all contain mesh data that can be generated by you but is a large file size
4. etc/ needs to contain the .conf files for mangosd and realmd. The .conf.dist are examples.
