# This folder must be populated by you
```
data
├── dbc # you supply
├── etc
│   ├── mangosd.conf # you must create, mangosd.conf.dist is an example
│   └── realmd.conf  # you must create, realmd.conf.dist is an example
├── maps  # you supply or generate (one time only)
├── vmaps # you supply or generate (one time only)
├── mmaps # you supply or generate (one time only)
├── mysql # Will be autogenerated if you use defaults, will persist
│   ├── aria_log.00000001           # generated by db container after 1st run
│   ├── aria_log_control            # generated by db container after 1st run
│   ├── ddl_recovery-backup.log     # generated by db container after 1st run
│   ├── ib_buffer_pool              # generated by db container after 1st run
│   ├── ibdata1                     # generated by db container after 1st run
│   ├── ib_logfile0                 # generated by db container after 1st run
│   ├── init
│   │   └── 01-emptydb-init-tortoise.sh
│   ├── mariadb_upgrade_info        # generated by db container after 1st run
│   ├── multi-master.info           # generated by db container after 1st run
│   ├── mysql                       # generated by db container after 1st run
│   ├── performance_schema          # generated by db container after 1st run
│   ├── sys                         # generated by db container after 1st run
│   ├── undo001                     # generated by db container after 1st run
│   ├── undo002                     # generated by db container after 1st run
│   └── undo003                     # generated by db container after 1st run
├── README.md

```
1. We do not add DBC due to Blizzard Entertainment copyrighted material
1. mysql/init/*.sh will be ran inside of docker containers to initialize the db. Mangosd will fill most of it.
1. If the database container is ran empty an initalized database will be setup in mysql/ the above example has what those files look like after being initalized
1. ./maps/ ./mmaps ./vmaps/ all contain mesh data that can be generated by you but is a large file size
1. etc/ needs to contain the .conf files for mangosd and realmd. The .conf.dist are examples.
